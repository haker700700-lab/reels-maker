🔗 صانع الريلز v4.1 — الحسابات والنشر التلقائي
================================================
فين الجديد؟  الخصائص والإعدادات ← «🔗 الحسابات والنشر التلقائي»

الإعدادات (فوق)
  ⏸ إيقاف تنزيل الريلز على الموبايل   — الريلز بتفضل على السيرفر ومش بتتنزّل عندك.
  🚀 تشغيل النشر التلقائي              — الريلز بتتجدول وتتنشر على السيرفر. تقدر تفعّل الاتنين مع بعض.

الحسابات (كل منصة بكارت): فيسبوك (صفحات) • إنستجرام • تيك توك • يوتيوب Shorts
  • «+ ربط»: بيفتح نافذة تسجيل الدخول الرسمي للمنصة، وبعد الدخول تطلع نافذة تأكيد.
  • فيسبوك: بيجيب صفحاتك وحسابات إنستجرام المربوطة بيها، وتختار فين تنشر (واحدة أو أكتر).
  • اضغط على أي حساب: وصف ثابت للحساب (فاضي = ينشر من غير وصف) + «أول ريل بعد X ساعة» + «كل ريل بعد Y ساعة».
  • تقدر تضيف أكتر من حساب/صفحة لكل منصة، وتوقف أي حساب بالعلامة.
  • إكس • سناب شات • بنترست • لينكدإن: أماكنها جاهزة (قريبًا).

الجدولة والمتابعة (📅)
  لكل حساب: كام ريل متجدول / اتنشر / فشل، وآخر ميعاد في جدوله.
  لما تعمل رابط تاني، ريلزه بتتجدول تلقائيًا بعد آخر ميعاد لكل حساب. تقدر «تنشر دلوقتي» أو «تلغي المجدول» أو «تعيد الفاشل».

إزاي بينشر والموبايل مقفول؟
  أول ما تبعت الرابط: السيرفر يصنع الريلز ← يحطها في جدول كل حساب (داخل الخزنة المشفّرة)
  ← ناشر على GitHub بيصحى كل 5 دقايق وينشر اللي معاده جه. الموبايل مش مطلوب بعد إرسال الرابط.

الخصوصية
  • الحسابات والتوكنات والمفاتيح مخزّنة في فرع «vault» بمستودعك، مشفّرة AES-256-GCM، والمفتاح من توكن تطبيقك (سرّك).
    المستودع عام لكن الملف مجرد بايتات مشفّرة. كل مستخدم بيعمل مستودعه وتوكنه، فمحدش بيشوف حسابات غيره.
  • مفيش توكن بيتطبع في أي لوج، ولا بيتخزن نص عادي على الموبايل.
  • لو غيّرت التوكن (RESET_TOKEN=1) الخزنة القديمة مش هتتفك — اربط الحسابات تاني (دقيقة).

التحديث
  bash update-reels.sh   (زي ما هو). أول مرة بس هيطلب توكن جديد بصلاحيتين: Actions + Contents (Read and write).

مفاتيح المطوّر (مرة واحدة لكل منصة — زر 🔑 في الكارت)
  عشان المشروع عام، كل مستخدم بيعمل تطبيق مطوّر مجاني بتاعه (ده اللي بيخلّي حسابك مش بيتشارك مع حد):
  • Meta (فيسبوك+إنستجرام): developers.facebook.com ← App نوع Business ← Facebook Login ← Valid OAuth Redirect URI:
        https://www.facebook.com/connect/login_success.html
    وخلّي حسابك Admin/Tester. (من غير مراجعة Meta بتنشر على صفحاتك أنت بس — وده المطلوب.)
  • تيك توك: developers.tiktok.com ← Login Kit + Content Posting API ← Redirect URI: https://github.com/<حسابك>/reels-maker
  • يوتيوب: Google Cloud ← YouTube Data API v3 ← OAuth client نوع «TVs and Limited Input devices» ← ضيف نفسك Test user.
  التطبيق بيعرض لك الرابط الصح ويقدر ينسخه.

حدود صريحة (من المنصات نفسها، مش من التطبيق)
  • جروبات فيسبوك والملف الشخصي: فيسبوك قفل النشر عليهم بالـ API. بنشر على الصفحات (Pages) بس.
  • إنستجرام: لازم حساب Business أو Creator مربوط بصفحة فيسبوك.
  • تيك توك: لحد ما تيك توك يراجع تطبيقك، الفيديوهات بتنزل «أنا فقط» (خاصة). بعد المراجعة بتنزل عام.
  • يوتيوب: تطبيق الاختبار بيخلّي الربط يتجدد كل 7 أيام لحد ما تنشر تطبيقك؛ لو انتهى التطبيق هيقولك تربط تاني.
  • GitHub بيوقف الجداول التلقائية لو المستودع ما اتحرّكش 60 يوم؛ استخدام التطبيق بيحرّكه، ولو وقف شغّله من تبويب Actions.
  • الريلز المجدولة بتتحمي من المسح التلقائي لحد ما تتنشر.
