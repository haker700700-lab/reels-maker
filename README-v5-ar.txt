🎬 صانع الريلز v5 — اللي اتضاف
================================
🎛️ «الاستوديو» (زرار جديد في الشاشة الرئيسية)
  كل قسم فيه شرح صغير + «مكانه» على الشاشة، وفوق معاينة ٩:١٦ بتبيّن مكان اللوجو والنص والمصدر وشريط التقدّم والفلتر لحظيًا.

  🏆 الوضع (الافتراضي: «الأفضل»)
     • الأفضل: قص بالطول + أحسن اللحظات + وجوه + تحسين صورة + فلتر سينمائي خفيف + تعتيم أطراف + حدّة + صوت نضيف
       (وضوح كلام + تنقية دوشة + توحيد مستوى) + خفض الموسيقى وقت الكلام + حركة نص + شريط تقدّم.
     • Pro: فلتر ذهبي + وضوح + حبيبات + تكبير بطيء + حركة نص «ينزلق» + صوت أعلى.
     • مخصّص: بس اللي تعلّم عليه.
     الوضع الجاهز بيشغّل توليفته، وأي حاجة تختارها فوقه بتتضاف/بتغلب (فلتر اخترته = فلترك).
  🎨 الفلاتر: ذهبي ✨ • غروب • سينمائي • كلارندون • جونو • لارك • فالنسيا • فينتاج • أبيض وأسود • مون • زاهي • مات • بارد • دراما • وهج ناعم
     + شدّة (30/50/70/100%) + إضافات: تعتيم الأطراف • حبيبات • حدّة • وضوح • تثبيت خفيف • تنظيف الصورة.
     (فلاتر «على غرار» إنستجرام مبنية بـ ffmpeg — مش نسخ مطابقة لفلاتر إنستجرام.)
  🏷️ اللوجو: رابط صورة أو «📁 رفع» من الجهاز (بيترفع كملف إصدار على الريبو زي الموسيقى). المكان (٥ أماكن) • الحجم • الشفافية.
  📝 النص: مكان (أعلى/وسط/أسفل) • حجم • نمط (ساده بس، صندوق داكن/أبيض/ذهبي/أسود/بنفسجي، نيون، أصفر بحدود) • خط • لون • حركة ظهور
     + سطر مصدر/شكر صغير فوق. (النص نفسه بتكتبه في الشاشة الرئيسية زي ما كان.)
  🎞️ حركة: شريط تقدّم • تكبير بطيء.
  🔊 الصوت: بيعرض الإعداد الحالي (الموسيقى الافتراضية = الهادئة المدمجة، مستوى 8%، الصوت الأصلي شغّال، توحيد -16 LUFS)
     + توحيد المستوى • وضوح الكلام • تنقية الدوشة • ضغط • باص • حدّة • خفض الموسيقى وقت الكلام (Ducking) • مستوى الصوت الأصلي.
  📜 سجل الحقوق: ملف rights.txt جوه reels.zip (التاريخ + موقع المصدر فقط + إقرارك).
  ▶️ فيديو تجريبي ١٠ ثواني: بيتولّد على السيرفر من غير تحميل، بيتطبّق عليه كل اختياراتك، وبيطلعلك:
     reel_00_before.mp4 (قبل) + reel_01.mp4 (بعد) + effects.txt (ملخص بكل تأثير اتطبّق). مابيتنشرش على أي منصة.
  أزرار تحت: «💾 حفظ كافتراضي» و«↩️ رجوع للأصلي (الأفضل)».

𝕏 النشر على X (تويتر سابقًا)
  زرار «𝕏 إكس» زي فيسبوك/إنستا/تيك توك: تفعّل النشر من السيرفر + نص التغريدة + أكتر من حساب.
  كل حساب ليه ٤ مفاتيح من developer.x.com (API Key / API Secret / Access Token / Access Token Secret) والتطبيق بيشفّرهم (نفس نظام باقي المنصات، Secret TT_PRIV).
  لازم صلاحية التطبيق «Read and write» قبل ما تولّد الـ Access Token. حدود النشر ورفع الفيديو بتحددها باقة حسابك المطوّر عند X.
  السيرفر بيرفع الفيديو بالأجزاء عن طريق X API v2 وينشر تغريدة، والسبب بيظهر في التقرير لو X رفض.

التحديث (Termux) — زي ما كان
  termux-setup-storage
  pkg install -y unzip && unzip -o ~/storage/downloads/reels-maker-v5.zip -d ~ && bash ~/reels-maker-main/termux-update.sh
  وبعدها ابني APK جديد (apk.yml). مهم: الـ workflow بقى فيه مدخل جديد اسمه adv (آخر مدخل من 25 المسموحين) — لازم reels.yml يتحدّث على الريبو (سكريبت التحديث بيعمل كده).

ملاحظات صريحة
  • مفيش «وضع لتخطي حقوق الفيديوهات»: ده مش بيتعمل (تفادي كشف الحقوق/Content ID تحايل على حقوق صاحب المحتوى). المتاح هو الوضع الأفضل/Pro + سجل الحقوق + سطر المصدر.
    «وضع الريأكشن» القديم زي ما هو ومابيضمنش أي حاجة.
  • الفلاتر والصوت والفيديو التجريبي اتجرّبوا فعليًا على ffmpeg 6.1. كود الأندرويد (الاستوديو وX) اتكتب بس ماتبناش APK ولا اتجرّب على جهاز.
    ونشر X ماتجرّبش على X فعلًا؛ توقيع OAuth اتطابق مع المثال المنشور من تويتر، والباقي حسب توثيق API v2.
  • واجهة الويب المحلية (Termux) ماتعدّلتش؛ الاستوديو في تطبيق الأندرويد والسحابة. المحرك نفسه بيقبل adv لو بعتّه.
  • لو أي خاصية v5 فشلت وقت التصيير، الريل بيتعمل بالأساسيات بدل ما يفشل، وبيتقال لك إيه اللي اتشال.
