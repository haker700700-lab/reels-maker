النشر على إنستجرام من السيرفر (v4.8) — زي الفيسبوك بالظبط
1) حدّث الملفات على الريبو (خصوصًا .github/workflows/reels.yml و cloud/instagram_post.py) وابنِ APK جديد. نفس مفتاح التشفير (TT_PRIV / TT_PUB) — مفيش حاجة جديدة.
2) جهّز الحساب: لازم Business أو Creator (إنستجرام ← الإعدادات ← نوع الحساب ← التحويل لحساب احترافي)، ومربوط بصفحة فيسبوك أنت أدمن عليها.
3) من developers.facebook.com اعمل تطبيق (نوع Business) وسيبه Development. في Graph API Explorer اطلب الصلاحيات:
   instagram_basic + instagram_content_publish + pages_show_list + pages_read_engagement
   (نفس توكن الفيسبوك بيشتغل لو فيه الصلاحيات دي). اضغط Generate Access Token وسجّل دخول بحساب فيسبوك الأدمن، واختار كل الصفحات/الحسابات اللي عايزها.
4) التطبيق ← «📷 إنستا» ← الصق التوكن ← «➕ إضافة حساباتي من التوكن». بيجيب كل حسابات إنستجرام المربوطة لوحده ويشفّر توكن كل حساب قبل الحفظ.
5) فعّل «انشر على كل حسابات إنستجرام من السيرفر» (و«من غير تنزيل» لو عايز) وابدأ الريلز. العلامة ✓ على زر «📷 إنستا» في الصفحة الرئيسية معناها إنه مفعّل.

أكتر من حساب
- كلهم على نفس حساب فيسبوك: توكن واحد بيضيفهم كلهم مرة واحدة (اختار كل الصفحات وقت التفويض).
- حساب فيسبوك تاني: ولّد توكن بيه وكرر الخطوة 4؛ بيتضاف فوق الموجود.
- تحديث حساب (توكن جديد): أضفه تاني وبيستبدل القديم. «حذف» جنب أي حساب بيشيله.

ملاحظات
- النشر رسمي عن طريق Instagram Content Publishing API (Reels) بالرفع المباشر من السيرفر، فمفيش متصفح ولا كلمة سر ولا تحقق، والفيديو مش محتاج رابط عام.
- الحد: 100 منشور بالـ API لكل حساب في 24 ساعة. السيرفر بيقرا الحد قبل ما يبدأ.
- التوكن القصير بيعيش ساعات. لتوكن طويل: Access Token Debugger ← Extend Access Token قبل اللصق (توكن الصفحة الناتج منه بيبقى من غير انتهاء).
- لو التوكن انتهى أو الصلاحية ناقصة التقرير بيقول كده؛ أضف الحساب تاني.
- بيشتغل مع التك توك والفيسبوك مع بعض: التقرير بيظهر الثلاثة (🎵 📘 📷).
- اقفل المستودع خاص.

الصفحة الرئيسية (v4.8): كل حاجة على شاشة واحدة من غير تمرير. الجودة (1080/720) ومستوى صوت الموسيقى بقوا زرّين بيلفوا بالضغط، والأسماء جوه الخانات، والخصائص وتيك توك وفيسبوك وإنستا في صف واحد.
