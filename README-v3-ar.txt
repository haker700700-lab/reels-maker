🎬 صانع الريلز v3 — اللي اتضاف
==============================
النص على الفيديو
  • سطر واحد دايمًا (الخط بيصغّر تلقائيًا ليناسب العرض، ولو النص طويل جدًا بيتقصّ آخره مع تنبيه).
  • خط Tajawal ExtraBold (مفتوح المصدر) + صندوق شفاف مدوّر + ظل، ومقاسه نسبي لعرض الفيديو (1080 / 720 / 9:16 / 4:5 / 1:1).

السرعة والنت
  • الشغل كله على سيرفر GitHub المجاني: موبايلك بيبعت الرابط وينزّل ملف reels.zip بس (الفيديوهات أصلًا مضغوطة؛ خفّضنا البت-ريت فالملف أصغر).
  • فيديو أطول من 40 دقيقة: بيتحمّل بجودة 720 على السيرفر (أسرع بكتير)، والريل بيطلع بالجودة اللي اخترتها.
  • تصيير ريلين في نفس الوقت على السيرفر.
  • نفس الرابط + نفس الإعدادات = بيستخدم النتيجة اللي اتعملت قبل كده فورًا (من غير إعادة شغل).
  • كل ريل من جزء مختلف من الفيديو (مفيش تداخل أو تكرار)، وكل عملية ليها رقم خاص (مفيش خلط بين الروابط).
  • الوقت المتوقع: 3 لـ 8 دقايق حسب طول الفيديو وسرعة موقع المصدر.

التطبيق
  • خدمة خلفية: بتكمّل لو قفلت الشاشة أو التطبيق، وبتستنى النت لو فصل وتكمّل التنزيل من حيث وقف.
  • السيرفر بيكمّل لوحده حتى لو الموبايل اتفصل بالكامل؛ لما ترجع تفتح التطبيق بيكمّل التنزيل.
  • إعدادات افتراضية: عدّل واحفظ «💾 حفظ كافتراضي»، وكل مرة تغيّر الرابط بس. «↩️ رجوع للافتراضي» و«🏭 الأصلية».
  • أول مرة: اسمح بالإشعارات واضغط «🔋 اسمح للتطبيق يشتغل في الخلفية».

التحديث (Termux)
  termux-setup-storage      (مرة واحدة، واضغط سماح)
  pkg install -y unzip && unzip -o ~/storage/downloads/reels-maker-v3.zip -d ~ && bash ~/reels-maker-main/termux-update.sh
  الأمر بيرفع التحديث، يبني الـ APK على GitHub، وينزّل ReelsMaker.apk في «التنزيلات».
  (التوكن بيتسأل عنه مرة واحدة بس لو مش موجود. لتغييره: RESET_TOKEN=1 bash termux-update.sh)
