النشر على صفحات الفيسبوك من السيرفر (v4.5)
1) شغّل أمر التحديث وثبّت الـ APK (نفس مفتاح التشفير بتاع التك توك، مفيش حاجة جديدة تتعمل).
2) من developers.facebook.com اعمل تطبيق (Business) وسيبه Development، وفي Graph API Explorer اطلب
   pages_show_list + pages_manage_posts + pages_read_engagement وسجّل دخول بحسابك (لازم تكون أدمن على الصفحات)،
   وبعدين Generate Access Token. (لو عايز توكن طويل: Access Token Debugger ← Extend Access Token.)
3) التطبيق ← «📘 فيسبوك» ← الصق التوكن ← «➕ إضافة صفحاتي من التوكن». بيجيب كل صفحاتك لوحده ويشفّر توكن كل صفحة قبل الحفظ.
4) فعّل «انشر على كل صفحاتي من السيرفر» (و«من غير تنزيل» لو عايز) وابدأ الريلز.
- النشر رسمي عن طريق Reels Publishing API، فمفيش متصفح ولا كلمة سر ولا تحقق.
- حد فيسبوك: 30 ريل لكل صفحة في 24 ساعة. لو التوكن انتهى أو الصلاحية ناقصة التقرير بيقول كده؛ أضف الصفحات تاني.
- بيشتغل مع التك توك مع بعض: التقرير بيظهر الاتنين.
- اقفل المستودع خاص.
