🎬 صانع الريلز v6 — شكل جديد + استوديو برو الموحّد
===================================================
صنع بكل حب — adel mohamed ❤

🎨 الشكل
  • ألوان هادية مريحة للعين (خلفية داكنة مزرقّة + تركواز ناعم + أزرق فاتح) بدل البنفسجي الصارخ — مطبّقة على كل الشاشات.
  • أيقونة تطبيق احترافية جديدة (موبايل ٩:١٦ + زرار تشغيل + نجمة) — Adaptive Icon + أيقونة دايرة + Themed icon (أندرويد 13+).
  • الصفحة الرئيسية ثابتة من غير طلوع ونزول، وفوقها: الشعار + «صنع بكل حب adel mohamed ❤» + زرار شرح «؟».
  • شريط الحالة العلوي: (الخدمة • الوضع • عدد الخصائص • عدد منصات النشر) — اضغط عليه يطلعلك ملخص بكل حاجة شغّالة.
  • كل حقل ليه اسم صغير وشرح، ومنصات النشر عليها حالة (● شغّال / موقوف).
  • خفيف: من غير أي مكتبات أو صور؛ الشعار مرسوم بالكود.

🎛️ استوديو برو (كل الخصائص جوه، ومتناسقة)
  اتنقل له من الصفحة الرئيسية: عكس الفيديو • موسيقى الخلفية (مستوى + رابط/رفع ملف) • أغاني الفيديو الأساسية (تلقائي)
  • الريأكشن • الموسيقى كملف منفصل • صوت الفيديو الأصلي • وكل مربعات «الخصائص» القديمة (شاشة الخصائص اتشالت واندمجت هنا).
  كل خاصية: أيقونة + اسم + شرح + مفتاح تشغيل/إيقاف.
  منع التناقض:
    – الوضع الجاهز (الأفضل/Pro) بقى بيظبط المفاتيح نفسها، وأي تعديل منك بيحوّله «مخصّص» لوحده — فمفيش حاجة شغّالة غصب عنك.
    – «تتبّع الوجوه» و«قص بالطول» مربوطين: تشغّل الوجوه يشغّل القص، تقفل القص يقفل الوجوه.
    – «تنقية الدوشة» كانت متكرّرة في مكانين، بقت مفتاح واحد.
    – تنبيهات تلقائية فوق (مثلًا: صوت الفيديو مقفول ومفيش موسيقى = ريل صامت، أو العكس بيعكس الصوت كمان).

🎯 التقطيع الجديد (اللقطات المهمة)
  القديم كان بيفضّل الأصوات العالية فكان بيجيب الأغاني. الجديد (engine.py) بيختار بـ:
    حركة/أكشن + قطعات المشهد + وجوه + مؤثرات صوت (ضحك/صراخ/ضربة/كلام متقطّع) + وضوح الصورة،
    والصوت المستمر (الأغاني) بيتقيّم واطي عمدًا.
  نوع اللقطات (من الاستوديو): الكل • أكشن • كوميدي • حب ودراما (كل نوع بأوزان مختلفة).
  اتجرّب على فيديو تجريبي فيه أغنية مستمرة + مشهد حركة: اختار مشهد الحركة مش الأغنية، وشغّال end-to-end.

➕ إضافات برو جديدة: ألوان نابضة (Vibrance) • تفتيح الإضاءة الضعيفة • نعومة البشرة • نوع اللقطات.
