☁️ صانع الريلز السحابي — موبايلك بيبعت الرابط بس، والشغل كله على سيرفرات GitHub (مجانية ومفتوحة)
=================================================================================================

ليه ده أحسن لموبايلك؟
- مفيش تحميل فيديو على نتك، ولا تقطيع على معالج الموبايل، ولا حرارة ولا بطارية.
- لو النت ضعيف أو فصل بعد ما تدوس «Run» — الشغل مكمّل لوحده على السيرفر.
- في الآخر تنزّل ملف واحد بس: reels.zip

التجهيز (مرة واحدة — حوالي 3 دقايق، ممكن من موبايلك)
-----------------------------------------------------
1) اعمل حساب مجاني على github.com (لو معندكش).
2) اعمل Repository جديد، سمّيه مثلًا: reels-maker  — واختار Public (عام).
3) ارفع محتويات المجلد ده كلها جوّاه (بما فيها مجلد .github).
   الأسهل من الكمبيوتر: Add file ← Upload files (اسحب كل الملفات والمجلدات).
   مهم: لازم المسار يبقى  .github/workflows/reels.yml
4) ادخل تبويب Settings ← Actions ← General ← Workflow permissions
   واختار «Read and write permissions» ثم Save.

الاستخدام (كل مرة)
------------------
1) افتح الريبو ← تبويب Actions ← «🎬 صانع الريلز (سحابي)» ← Run workflow.
2) الصق الرابط، علّم «أؤكد أني أملك الحقوق»، عدّل الإعدادات لو عايز، واضغط Run workflow.
3) اقفل الصفحة وسيب الموبايل — الشغل بياخد من 3 لـ 15 دقيقة تقريبًا حسب طول الفيديو.
4) افتح الـ run لما يخلص (علامة ✅) وهتلاقي في الملخص لينك «تحميل reels.zip».
   أو من تبويب Releases (على يمين صفحة الريبو) — الرابط عام وبيتحمّل من غير تسجيل دخول.

ملاحظات صريحة
-------------
- كل حاجة عامة: الريبو، والريلز اللي بتطلع في Releases، أي حد معاه الرابط يقدر ينزّلها.
  عشان كده استخدمه على فيديوهات تملكها أو مصرّح لك بيها فقط.
- بيحتفظ بآخر 15 إصدار بس وبيمسح الأقدم تلقائيًا.
- يوتيوب أحيانًا بيمنع السيرفرات ويطلب «تأكيد إنك مش روبوت». روابط مباشرة (mp4/m3u8) وأغلب المواقع
  التانية بتشتغل عادي. لو يوتيوب رفض: Settings ← Secrets and variables ← Actions ← New secret
  باسم YT_COOKIES والصق فيه محتوى ملف cookies.txt (صيغة Netscape) من حسابك. الكوكيز سر مش بيظهر لأي حد.
- الخدمة مجانية بلا حد للريبوهات العامة، لكن لها سياسة استخدام عادلة من GitHub — مش للاستخدام الكثيف جدًا.
- نسخة Termux القديمة لسه موجودة جوّه نفس المجلد (README-ar.txt) لو احتجتها.

التشغيل خارج GitHub (اختياري)
-----------------------------

  echo '{"url":"الرابط","n":5,"rights":true}' > settings.json
  python engine.py --run settings.json
